# Universal YouTube Script Engine

This skill turns a topic (plus a few optional parameters) into a complete,
ready-to-record voiceover script for an informational YouTube video — in any
niche: history, finance, science, technology, cars, sports, space, disasters,
crime, business, biographies, nature, and beyond. The method below is a
proven retention-focused methodology; follow it faithfully rather than
improvising a generic "AI essay."

## Step 1 — Gather the input parameters

The full parameter set is:

- **TOPIC** — the video's subject
- **FORMAT** — documentary story / investigation / biography / explainer / ranking / comparison / evolution of a subject / other
- **TARGET AUDIENCE** — age, level of knowledge, interests
- **DURATION** — desired minutes or words
- **LANGUAGE** — script language
- **TONE** — restrained / tense / analytical / conversational / popular-science / other
- **CORE PROMISE** — what the viewer should understand or learn by the end
- **REQUIRED FACTS** — facts, events, names, or elements that must be included
- **SOURCES** — links, documents, notes, or permission to research independently
- **CONSTRAINTS** — what must not be mentioned, which wordings or themes to exclude
- **CALLS TO ACTION** — none / subscribe / comment / other

Don't turn this into a rigid interrogation. If the user's request already
gives you enough to work with (a topic, and maybe a hint of format, length,
or audience), fill in the rest with reasonable defaults and proceed — most
users just want a good script, not a form to fill out. Only ask a quick
clarifying question when something that matters a lot is genuinely
ambiguous (for example: the topic itself is unclear, or the duration is
wildly important to know and wasn't given at all). Reasonable defaults:
language = the language the user is writing to you in; tone = analytical/
restrained; calls to action = none, unless the user's channel style suggests
otherwise; duration = ~8-12 minutes if nothing is specified.

If the topic is based on real events and the user hasn't supplied sources,
and the topic involves current or contested facts, ask for sources or for
permission to research before inventing details — see the fact-discipline
rule below.

## Step 2 — Silent pre-analysis

Before writing the script, silently determine (do not show this analysis to
the user unless they specifically ask for it):

1. The core promise of the video.
2. The strongest fact, moment, or result.
3. The central contradiction.
4. The emotion or thought that should stay with the viewer.
5. Three to five information loops that will be opened and then closed.
6. The structure that fits the format (see below).
7. The facts that require especially careful verification.

## Step 3 — Write the script

Write one continuous voiceover text meant to be read top to bottom by a
single narrator. Follow every rule below — they work together to build and
hold retention across the whole runtime, not just in isolated spots.

### Choose the structure that fits the format

Don't reuse the same skeleton for every topic — pick (or hybridize) the one
that fits:

- **Documentary story**: Decisive moment → the minimum necessary background → the first change → the mounting consequences → the point of no return → the peak → the aftermath.
- **Investigation**: A specific claim or discrepancy → the first evidence → alternative explanations → new contradictions → the strongest evidence → the limits of what is known → the current state of the question.
- **Biography**: The defining moment of the life → origins → the first breakthrough → the period of growth → the peak → the conflict or change → the consequences → the legacy or the unresolved question.
- **Explainer**: An unusual result or contradiction → a simple working model → the key elements → concrete examples → the exceptions → the practical consequences → the closing takeaway.
- **Ranking or tiers**: The contrast between the lowest and highest tier → a clear criterion for the ordering → a consistent reveal of the tiers → the distinct value of each tier → a shift in scale → a final tier that reframes the entire list. Each next item must differ from the previous one not only in price, size, or number, but in a new quality, access, capability, risk, influence, or consequence.
- **Comparison**: The main difference → the criteria for comparison → a consistent test of each criterion → the cases where the usual conclusion fails → a verdict that accounts for context.
- **Evolution of a technology, object, or phenomenon**: The original problem → the first working solution → its limitations → a series of improvements → the turning point → the current state → the next unsolved barrier.

If the topic doesn't fully fit any single structure, build a hybrid, but
keep a clear forward motion throughout.

### The opening

The first two sentences decide whether the viewer stays or leaves. Open
with one of four options: a specific moment already in motion; a powerful
result; a number that changes the scale of the topic; or a contradiction
between two facts that shouldn't go together.

Use three fast beats, all within the first thirty seconds:

1. Put the viewer inside the event, result, or contradiction.
2. Show that the usual explanation stops working.
3. Establish the scale, cost, or consequences.

Do not open with: general background; a greeting; a definition of the
topic; a question to the viewer; "in this video"; "you probably already
know"; "few people know"; "it all started with"; or an empty promise of a
future shock. Don't use intrigue without substance — the first seconds must
already deliver a real fact.

### Write like a reporter

Short declarative sentences. Precise nouns, concrete verbs. Real names,
places, dates, sums, and specifications only when confirmed.

Avoid: metaphors for the sake of beauty; poetic descriptions; artificially
dramatic adjectives; emotional commands to the viewer; phrases like "this is
incredible," "this is shocking," "impossible to imagine." Don't tell the
viewer what to feel — let the facts create the reaction.

After a long sentence, use a short one. Don't stack three complex sentences
in a row. Every period should feel like a natural pause for the voice.

### Build retention on contradictions

Look for the collision between: price and real value; reputation and
result; size and influence; expectation and fact; the official version and
the documents; a familiar pattern and the exception; outward simplicity and
inner complexity. Don't restate a contradiction several times — place the
facts side by side and move the story on.

### Every paragraph must perform a function

Keep a paragraph only when it does at least one of: delivers a new fact;
changes the understanding of an earlier fact; moves the story forward;
raises the stakes; complicates the situation; closes an open information
loop; opens a new loop; gives the viewer a concrete reward for their
attention. If a paragraph only restates what was already said in other
words, delete it. An interesting fact alone isn't enough — it must connect
to the core promise of the video.

### Open information loops

Open three to five information loops over the course of the script. A loop
isn't necessarily a direct question — it can be an unusual detail left
unexplained for now; a mismatch in the numbers; a decision whose
consequences aren't yet known; a person or object whose role is revealed
later; or a fact that changes meaning once new context arrives. Don't open
too many loops at once. Close every loop the script promised to close.
Don't withhold an obvious answer artificially — if the viewer can already
guess it easily, give the answer and open the next loop.

### Give micro-rewards

Roughly every forty to sixty seconds, give the viewer a concrete payoff: a
reveal; an unexpected number; the answer to a small question; a change of
scale; an exception to the rule; a consequence that changes an earlier
fact; a move to the next level of the story. Don't save all the valuable
information for the finale — the middle of the script must contain no fewer
useful reveals than the beginning.

### Shift the emotional key

Don't hold the script in one emotional key for more than two or three
paragraphs. Alternate: tension and clarity; scale and human detail; a
problem and a temporary solution; success and its cost; a complex
explanation and a simple example; the public version and the hidden
limitation. Constant tension stops working without periodic release.

### Ration your numbers

Don't use more than three precise numbers in one meaningful scene. Keep
precise only the figures that prove scale, show a contradiction, change the
understanding of the situation, or are needed for a comparison. Round
secondary numbers. Don't overload the voiceover with long dates,
specifications, and strings of percentages.

### Use transitions without filler

Never write: "but here's where it gets interesting"; "and now the main
thing"; "what happened next shocked everyone"; "you're probably wondering";
"let's break it down"; "let's jump to"; "it's worth noting";
"interestingly"; "it's important to understand." Move directly to the next
fact, consequence, time, or place.

### Handle calls to action with discipline

No more than two calls to action in the entire script. Never in the first
seconds. The first call is allowed after the viewer has already received
valuable information, but before the strongest part of the script. Tie a
subscribe request to a clear promise of future value. Never place a call to
action right after a tragedy, a death, an emotional confession, or another
heavy moment. A call to action must not break the tone of the story.

### If the topic is based on real events

Use only documented facts. Do not invent: direct speech; a person's
thoughts; private conversations; exact times; motive; the sequence of
actions; a cause-and-effect link that isn't in the sources. Separate a
confirmed fact from a supposition. Attribute contested claims to a specific
source or side. If reliable data is insufficient, don't fill the gap with a
plausible version. If sources contradict each other, state that briefly and
precisely. If the user hasn't provided sources and the topic requires
current or contested data, ask for permission to research, or ask for
source materials, before writing.

### The ending

First close the core promise of the video and all essential information
loops. Leave unresolved only the question that genuinely has no confirmed
answer — don't manufacture a mystery where a known explanation exists. End
in one of three ways: a plain fact; a concrete consequence; a genuine open
question. Never end with a moral, a motivational speech, a recap of the
whole script, or a long subscribe pitch. The final sentence should add
meaning, not restate the conclusion.

## Step 4 — Final silent check

After writing, silently check the script against this list, and fix every
problem found before delivering the result:

- Does the opening deliver on the promise of the first thirty seconds?
- Does a concrete fact appear in the first two sentences?
- Is it clear why the topic matters?
- Is the chosen structure right for the format?
- Is there movement, not just a sequence of facts?
- Does the viewer get a micro-reward roughly every minute?
- Do neighboring paragraphs differ in function or key?
- Are the promised information loops closed?
- Are there no repetitions of one conclusion in other words?
- Are there no filler transitions?
- Are there no unconfirmed details?
- Can any paragraph be removed without loss of meaning?
- Is the text comfortable to read aloud?
- Does the length match the target duration within ten percent?
- Does the final sentence add new meaning?

## Output

Output only the finished voiceover text. Do not add headings, timecodes,
explanations, author's notes, descriptions of the visuals, or comments on
the structure — unless the user specifically requests them.
